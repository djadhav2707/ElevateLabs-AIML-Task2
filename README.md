# ElevateLabs-AIML-Task2

## Task 2: Exploratory Data Analysis (EDA)

### Objective
Perform Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

### Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

### Steps Performed
- Loaded the Titanic dataset.
- Displayed dataset information.
- Generated summary statistics.
- Created histograms for numerical features.
- Created boxplots for Age and Fare.
- Generated a correlation matrix.
- Created a pairplot for selected features.
- Made observations from the visualizations.
